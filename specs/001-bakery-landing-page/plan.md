# Implementation Plan: Bakery Landing Page

**Branch**: `dev` | **Date**: 2026-08-21 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/001-bakery-landing-page/spec.md`

## Summary

A single, Spanish-language landing page for the "Dulces Lore" bakery presenting the business
name/tagline, product highlights, address/hours, a "social media coming soon" note, and a
prominent WhatsApp contact button pre-filled with a greeting message. Built as a minimal Rails
page (single controller action + view) with content sourced from a YAML config file and the
WhatsApp number read from an environment variable — no database is introduced for this feature.

## Technical Context

**Language/Version**: Ruby on Rails 7.1 (see [research.md](./research.md))

**Primary Dependencies**: Rails (routing, ActionController, ActionView); `dotenv-rails` for
loading `.env` in development

**Storage**: None (N/A) — content in `config/bakery.yml`, no ActiveRecord model for this feature

**Testing**: RSpec (request specs + a helper/view unit spec)

**Target Platform**: Web (server-rendered HTML, any modern browser, desktop and mobile)

**Project Type**: Web application (single Rails app, no separate frontend/backend split needed)

**Performance Goals**: Page loads and is interactive well within typical web page expectations
(no specific numeric target beyond SC-001's "locate WhatsApp link within 5 seconds", which is a
UX/layout concern, not a server performance concern)

**Constraints**: Must render entirely in Spanish; must not hardcode the WhatsApp number in source
code (FR-003); single self-contained page, no login/multi-step navigation (FR-007)

**Scale/Scope**: Single static page, single business profile, small number of product highlights
(handful, not paginated)
